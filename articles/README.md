# Bajet Malaysia Articles

Articles are stored as Markdown files and use YAML front matter for metadata.

## Structure

- `articles/dsr/` — debt and Debt Service Ratio content
- `articles/budgeting/` — budgeting and emergency-fund content
- Add new topic folders as the library grows.

## Article metadata

Each article should include:

- `title`
- `slug`
- `category`
- `tags`
- `published`
- `updated`
- `author`
- `description`
- `calculator` when a related calculator exists
- `status` (`draft`, `published`, or `archived`)

`data/articles.json` is the current article index. Keep it updated when adding or changing published articles.
