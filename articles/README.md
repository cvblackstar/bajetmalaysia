# Bajet MY Articles

Artikel disimpan sebagai fail Markdown supaya kandungan mudah disemak, dikemas kini dan diurus melalui Git.

## Struktur

- `articles/dsr/` — DSR dan hutang
- `articles/budgeting/` — bajet dan emergency fund
- Tambah folder topik baharu apabila perpustakaan artikel berkembang.

## Metadata wajib

Setiap artikel menggunakan front matter YAML dengan:

- `title`
- `slug`
- `category`
- `tags`
- `published`
- `updated`
- `author`
- `description`
- `calculator` jika ada kalkulator berkaitan
- `status` (`draft`, `published`, atau `archived`)

`data/articles.json` ialah indeks artikel yang digunakan oleh halaman panduan.
